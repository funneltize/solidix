# `@solidix/focus-guards`

Document-edge focus guards. Port of `@radix-ui/react-focus-guards`
(behavior-identical; mount/unmount handled via `onSettled` cleanup).

Mounts its guard elements imperatively and renders `children` through; takes no styling props.

## Differences from Radix

None: behavior-identical to Radix (mount/unmount handled via `onSettled` cleanup).
