# `@solidix/progress`

Progress primitive. Port of `@radix-ui/react-progress`.

Solid API mapping: `class` for `className`; `ref` is a plain prop; `asChild` composes via `@solidix/slot` (see the [Composition guide](../../../docs/composition.md)). Docs site: Progress page (`#/progress` route) with a live demo and API reference.

## Differences from Radix

None beyond the standard mapping above; behavior matches Radix.
