# `@solidix/separator`

Separator primitive. Port of `@radix-ui/react-separator`.

Solid API mapping: `class` for `className`; `ref` is a plain prop; `asChild` composes via `@solidix/slot` (see the [Composition guide](../../../docs/composition.md)). Docs site: Separator page (`#/separator` route) with a live demo and API reference.

## Differences from Radix

None beyond the standard mapping above; behavior matches Radix.
