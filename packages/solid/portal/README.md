# `@solidix/portal`

Portals content into a container. Port of `@radix-ui/react-portal`
(behavior-identical; built on Solid's `Portal` with the same mount-gated
`document.body` default).

Render `Presence` inside the portal, never around it; see the [Animation guide](../../../docs/animation.md) (Portal placement).

## Differences from Radix

None: behavior-identical to Radix (built on Solid's `Portal` with the same mount-gated `document.body` default).
