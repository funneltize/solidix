# `@solidix/visually-hidden`

Visually hidden primitive. Port of `@radix-ui/react-visually-hidden`
(behavior-identical; `ref` is a plain prop, no `forwardRef`).

Solid API mapping: `class` for `className`; `ref` is a plain prop; `asChild` composes via `@solidix/slot` (see the [Composition guide](../../../docs/composition.md)).

## Differences from Radix

None: behavior-identical to Radix (same visually-hidden styles on a `span`;
`ref` is a plain prop instead of `forwardRef`).
