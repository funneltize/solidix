# Backend system: philosophy pointer

Agent-ready source of truth for `@solidix/backend` is
`docs/backend-ui-design.md` in the repo root. Read that file before
adding, changing, or reviewing any backend token, shell part, data
part, style, test, demo, or doc. If that file and an implementation
disagree, the implementation wins only when a test pins it; otherwise
update the implementation to match the design doc.
